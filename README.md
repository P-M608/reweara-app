# Reweara — AI Fashion Stylist

เว็บแอปช่วยจัดการตู้เสื้อผ้า แนะนำการแต่งตัว และเตือนก่อนซื้อของซ้ำ

## วิธีเปิดใช้
ดับเบิลคลิกไฟล์ `index.html` เพื่อเปิดในเบราว์เซอร์ (Chrome, Safari, Edge) ได้เลย ไม่ต้องติดตั้งอะไร
ต้องต่ออินเทอร์เน็ต เพราะหน้าตาแอปและฟอนต์โหลดจากออนไลน์

> ทดลองบนมือถือ: ตอนนี้ยังต้องส่งไฟล์ไปเปิดในมือถือเอง ขั้นที่ 2 จะนำขึ้นเว็บจริงบน Firebase Hosting ให้เปิดจากลิงก์ได้
