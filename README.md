# Reweara — AI Fashion Stylist

เว็บแอปช่วยจัดการตู้เสื้อผ้า แนะนำการแต่งตัว และเตือนก่อนซื้อของซ้ำ

## วิธีเปิดใช้
- **ลองเร็ว ๆ (ยังไม่ตั้งค่า Firebase):** ดับเบิลคลิก `index.html` แอปจะเก็บข้อมูลไว้ในเบราว์เซอร์เครื่องนั้น
- **ใช้งานจริง (ล็อกอินและเก็บบน Cloud):** ทำตาม [FIREBASE_SETUP.md](FIREBASE_SETUP.md) ใช้เวลาประมาณ 15 นาที

ต้องต่ออินเทอร์เน็ต เพราะหน้าตาแอปและฟอนต์โหลดจากออนไลน์

## ไฟล์ในโปรเจกต์
| ไฟล์ | คืออะไร |
|---|---|
| `index.html` | ตัวแอปทั้งหมด |
| `firestore.rules` | กฎความปลอดภัยของฐานข้อมูล (ผู้ใช้เห็นเฉพาะข้อมูลตัวเอง) |
| `firebase.json` | ไฟล์ตั้งค่าสำหรับเครื่องมือ Firebase (ไม่ต้องแก้) |
| `FIREBASE_SETUP.md` | คู่มือตั้งค่าทีละคลิก |
